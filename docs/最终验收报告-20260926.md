## 1. 结论

本轮计划已实现并通过自动与真实服务验收：

- 千问是活跃代码中唯一语音 Provider；会话使用 Filetrans，短练习使用 Flash。
- DeepSeek `deepseek-flash` 负责复盘、场景分析、三题生成和回答反馈。
- 旧本地语音代码、依赖、镜像、测试和评测入口已完整迁入 `archive/local-speech-provider/`。
- 默认 API 镜像、Compose 和测试不再加载旧本地语音模型，也不存在 GPU Worker。
- Web、API、Qwen Worker、AI Worker、PostgreSQL、Redis、对象存储、网关和 OpenTelemetry 已在 Docker 中实际启动。
- 公开双人英语音频的真实 Qwen 短转写、Filetrans、任务恢复以及完整产品 API 闭环已通过。
- 真实 DeepSeek 冒烟、复盘、三题和回答反馈已通过。
- 本地真实用户验收入口已独立为 `http://127.0.0.1:18080`，不再依赖 Vite 或宿主机 FastAPI。
- `/admin/*` 中文业务后台六个页面已连接真实 PostgreSQL 数据，权限、筛选、分页、审计和安全重试均已实现。
- Prometheus、Grafana、Flower、PostgreSQL exporter 和 Redis exporter 已实际运行，四类采集目标全部在线，预置中文看板有真实数据。

尚需用户本人完成的不是代码缺口，而是只有真人能判断的三项：浏览器麦克风授权、真实双人录音中的本人身份选择，以及转写/说话人边界的主观听感抽检。

## 2. 本轮主要改动

### 2.1 千问唯一语音链路

- 分析 API 不再公开 `speech_backend`；旧客户端多传字段会被忽略。
- 服务端固定 `requested_backend=qwen`。
- 会话和短练习音频都要求逐次千问处理授权。
- 无授权返回 409；没有本地或模拟回退。
- Filetrans 任务 ID 在提交后立即持久化。
- Worker 恢复时直接轮询原任务，避免重复上传、提交和计费。
- 429、5xx 和网络错误可重试；错误 Key、权限和参数错误不重试。
- 结果保存模型、task ID、时长、耗时、usage、重试次数与恢复标记。
- 健康接口只报告千问；缺少 Key 时就绪检查返回 503。

### 2.2 DeepSeek 可靠性

- DeepSeek 只接收脱敏转写，不接收音频。
- 模型输出必须通过 Pydantic Schema 和 evidence ID 白名单校验。
- 本轮真实长会话曾出现“合法 JSON 但业务结构不合格”，现已加入严格 JSON Schema 和一次结构纠正重答。
- `PROMPT_VERSION` 升级为 `2026-09-26.2`，防止旧缓存掩盖新提示词。
- AI 任务会保存 `retryable`，前端能区分重试与管理员处理。

### 2.3 数据库和部署修复

- DeepSeek 题目允许最多 800 字符，`practices_v1.title` 已通过 Alembic `20260926_0004` 从 120 扩为 800，避免静默截断。
- 历史数据库的旧回退列保留以避免数据损失，但活跃 ORM/API 不读取或写入它们。
- Compose 显式为生产模式设置网关 HTTPS 前端地址和 CORS，修复 API 启动时安全校验失败。
- Celery 设置 `broker_connection_retry_on_startup=True`。
- API、Qwen Worker 和 AI Worker 将 `httpx/httpcore` 请求日志限制为 WARNING，避免常规日志记录 API Key、供应商请求细节或带签名的临时音频 URL。
- 生产与本地验收 Caddy 网关均过滤 Authorization、Cookie、CSRF 与 Set-Cookie 请求/响应头；探针值未出现在访问日志中。

## 11. 管理后台与监控验收补充

### 11.1 管理员接口与数据安全

- 未登录访问管理员接口返回 401，普通用户返回 403；自动测试覆盖全部新增接口。
- 概览支持 `24h/7d/30d`；用户、任务和审计均支持分页与筛选，任务额外支持起止日期并使用创建时间索引。
- 任务重试只创建新记录并保存 `retry_of_job_id`，不覆盖原失败记录；重复运行任务被阻止。
- 管理响应经过隐私断言，不包含音频对象键、临时地址、转写正文、任务 payload、完整模型输出或 API Key。
