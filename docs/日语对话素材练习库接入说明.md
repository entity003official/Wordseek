- 日语：来自精选 RealPersonaChat 只读库，共 624 条、8 个大类、55 个有内容的小类；
- 英语、中文：继续使用既有 10 条 Taskmaster-1 本地化素材；
- JMultiWOZ：本地包没有可核验的许可证信息，未进入精选库、接口或用户界面；
- AI 生成练习、复盘事件练习、千问转写/朗读和 DeepSeek 续聊入口保持不变。

运行时文件是 `backend/app/data/dialogue_practice_catalog.sqlite3`，大小约 0.85 MB。完整约 141 MB 的源数据库不会复制到应用、后端镜像或交付包。

## 构建规则

运行：

```powershell
python scripts/build_practice_materials_catalog.py
```

生成器默认读取工作区外层的 `data/dialogue-materials/dialogue_materials.sqlite3`，写出：

- `backend/app/data/dialogue_practice_catalog.sqlite3`
- `backend/app/data/dialogue_practice_catalog.report.json`

硬性筛选条件：

- 数据集必须是 `real_persona_chat_1_0_0`；
- `license_status` 必须为 `verified_from_local_license`，否则直接终止构建；
- `review_status=auto_accepted`；
- `quality_flags_json=[]`；
- `quality_score >= 3.5`；
- 每个小类最多 20 条。

片段必须至少包含两个交替说话人。开场优先选择分类关键词附近的疑问、请求或邀请句；隐藏上下文最多 6 个话轮、1600 个字符，不包含开场后的参考回答。说话人只保存为 `speaker_A`、`speaker_B` 等临时别名。

精选库不保存画像、人口属性、原始说话人 ID 或待复核状态。它只保存分类的中/英/日名称、关系、语体、来源数据集、版本、许可证、原始对话 ID 和必要练习片段。

## API

接口：`GET /api/v1/practice-library`

查询参数：

| 参数 | 可选值/默认值 |
|---|---|
| `target_language` | `zh`、`en`、`ja` |
| `native_language` | `zh`、`en`、`ja` |
| `category` | 大类代码，可省略 |
| `scene` | 小类代码，可省略 |
| `page` | 默认 1 |
| `page_size` | 默认 12，最大 24 |

响应包含大类及其小类、当前页素材、分页字段和来源署名。不存在的大类/小类返回 422；日语精选库缺失、损坏或版本不兼容时返回稳定错误码 `PRACTICE_CATALOG_UNAVAILABLE`，不会伪造备用素材。

## 页面行为与模型调用边界

- 目标语言变化时，页面组件重新建立，原大类、小类、页码和当前对话同时清空；
- 选择大类后，小类下拉框只显示该大类下有素材的选项；
- 点击素材后只把对方开场显示成第一条助手消息，不自动播放、不自动调用模型；
- 用户发送文字后才调用 DeepSeek 继续扮演对话对象；
- 用户主动点击朗读时才调用千问 TTS；
- 用户逐次同意并录音后才调用千问日语转写；
- 页面底部显示 RealPersonaChat 1.0.0 与 CC BY-SA 4.0 署名。
